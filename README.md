This is the frontend repository for **GLS eUniverse**, a thoughtfully designed mobile platform aimed at enhancing student services, improving campus security, and fostering meaningful alumni engagement.

The codebase includes the **Flutter-based mobile application code** all interacting seamlessly with a Django backend.

---

## 🎯 Problem Statement

University students often struggle with administrative delays, lack of digital ID accessibility, document requests, and weak alumni engagement. GLS eUniverse was born to fix this — with automation, digitization, and security in mind.

---

## 🧩 Core Features

### 🔐 Secure Access
- **JWT-based role authentication** using enrollment number (students) or email (others)

### 🆔 Digital Identity
- **QR code-based student/staff/alumni verification** for guards — no physical ID needed

### 🚪 Campus Visitor Logging
- Guards can capture visitor name, contact, photo, gate & time-in/out

### 👤 Profile Management
- All users (students, staff, alumni) can update their profiles

### 📬 Request Important Documents
- Online application for LORs, transcripts, duplicate mark sheets  
- Email notifications on approvals or updates

### 🧑‍💼 Admin Panel
- Program & profile creation (manual + bulk)
- User management, post approvals, and email communication

### 💬 Alumni Forum
- Alumni can post career opportunities and helpful discussions  
- Posts are shown after admin approval
